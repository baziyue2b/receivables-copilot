# 一分钟演示脚本

## 0-10 秒：项目目标

打开首页，说明这是一个本地运行的应收账款风险分析 Agent。强调财务指标由 Pandas 计算，模型只负责调用工具和解释结果。

## 10-25 秒：数据与指标

展示默认模拟数据和五个核心指标，然后依次指向账龄分布、客户风险敞口排行和账单明细筛选器。

## 25-40 秒：Agent 查询

输入：`未收金额最高的五个客户是谁？`

展示 Agent 调用工具后返回的客户排行，再输入：`分析晨曦医疗科技的回款风险。`

## 40-52 秒：文件校验

上传一个缺少字段或包含错误日期的文件，展示系统能明确指出错误字段和 Excel 行号，而不是产生错误分析。

## 52-60 秒：结果导出

点击下载 HTML 报告，展示报告中的核心指标、风险客户和建议。最后切回代码仓库，展示测试命令和 README。
